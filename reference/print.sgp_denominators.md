# Print method for sgp_denominators objects

Displays the estimation method, rate-conversion mode, years used, and
the denominator values for each scoring category. When bootstrap CIs are
present, the replicate count and CI level are also shown.

## Usage

``` r
# S3 method for class 'sgp_denominators'
print(x, ...)
```

## Arguments

- x:

  An `sgp_denominators` object returned by
  [`sgp_denominators()`](https://jdenn0514.github.io/rotostats/reference/sgp_denominators.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
